# 🌞 2D Solar System Simulation in Python 🌍

A realistic **Solar System simulation** built using **Python and Pygame**, where all eight planets revolve around the Sun following **Newton’s Law of Universal Gravitation**.  
Each planet displays its **name, orbit path**, and **distance from the Sun** in astronomical units (AU).

---

## 🪐 Features

- ☀️ Real-time orbital simulation of all 8 planets + Sun  
- 🌌 Logarithmic distance scaling for realistic visuals  
- 🧭 Displays planet names and distances dynamically  
- 💫 Smooth orbit trails for every planet  
- ⚙️ Based on gravitational physics and real-world constants  

---

## 🧠 Physics Behind It

Each planet’s motion is calculated using **Newton’s Law of Gravitation**:

\[
F = G \times \frac{m_1 \times m_2}{r^2}
\]

where  
- *G* = Gravitational constant (6.674×10⁻¹¹)  
- *m₁, m₂* = Masses of the two bodies  
- *r* = Distance between them  

The simulation updates each planet’s velocity and position per **timestep (1 day)** to create realistic orbital motion.
